# AFP RoyaBlog live theme

Listing cards are horizontal on desktop (photo at right, summary at left) and stacked on mobile. Only listing DOM is summarized; single-post bodies, links and FAQs remain intact. Native pagination and sidebar are preserved. Theme/telephone controls sit in the header on listings instead of overlapping cards. Both light and dark states were visually inspected.

Source of truth: the native template editor readback. Before editing again, fetch the live source and compare it with this file. The platform strips literal backslashes during saves; the added listing code deliberately contains none.
