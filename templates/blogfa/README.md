# AFP Blogfa native theme

Main and archive templates deployed through native ASP.NET form. Fluid 92% desktop width capped at 2200px; three cards above 1500px; mobile one column; full article reading width 760px.

The logo URL has exactly the same bytes/SHA256 as the user-supplied 200×200 PNG. Font: Vazirmatn with font-display swap. Actual product photos, not manufactured logo or imagery.

Six posts in native main/internal count settings. The publisher splits main content and continuation before submitting. Native archive next/previous blocks and all-post index links; provider docs do not promise a homepage numeric pager.

Google verification meta is in the static head. Server-rendered title, description, OG and RSS. Canonical uses actual location. No search-ranking or indexing guarantee.

Blogfa inserts rel=nofollow into external theme links on save. This provider transformation was verified and retained; exact comparison permits only that known addition.

No comment block. Automated post forms select disabled comments value 2.
