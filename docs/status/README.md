# پنل وضعیت وبلاگ‌ها

نشانی: https://getsalet.github.io/nono/status/

## برگه‌ها
- نمای کلی هفت وبلاگ، زمان آخرین انتشار و آمار ثبت‌شده.
- صفحه مستقل هر وبلاگ: رسیدها، صف، موانع کیفی، اجراها، زمان‌بندی و منابع.
- آرشیو انتشارها با جست‌وجو، فیلتر، صفحه‌بندی و خروجی CSV.
- وضعیت مخزن: آخرین commitها، نمونه ۱۰۰ اجرای اخیر، خطاهای دسترسی به منابع.
- راهنما و توضیح محدودیت شمارش.

## تعریف و تازگی داده
آمار تعداد پست‌ها از رسیدهای یکتای مخزن است، نه شمارنده تمام مطالب عمومی یا آمار بازدید. زمان انتشار از رسید می‌آید؛ وبلاگ‌ها هنگام نمایش پنل مستقیماً وارسی نمی‌شوند. شماره آخرین پست تعداد کل فرض نمی‌شود. بازیابی با زمان اولیه نامشخص در آمار ۲۴ ساعت/۷ روز وارد نمی‌شود. داده ناموجود، نامشخص است نه صفر.

دو درخواست API عمومی، commit و نمونه اجراها را دریافت می‌کنند. فایل‌ها در صورت دریافت SHA از همان نسخه ثابت خوانده می‌شوند؛ fallback به main صریح گزارش می‌شود. فایل‌های صف همه هفت وبلاگ پس از خواندن رسیدها خودکار بارگیری می‌شوند تا جست‌وجو و CSV به ترتیب بازکردن برگه‌ها وابسته نباشند. دریافت‌ها همچنان حداکثر شش درخواست هم‌زمان دارند. هنگام بارگذاری یا نبود عنوان واقعی، محدودیت جست‌وجو و CSV صریح نمایش داده می‌شود. کش صف به همان SHA محدود است؛ در حالت main بین تازه‌سازی‌ها استفاده نمی‌شود. ساعت نسبی هر ۳۰ ثانیه و داده‌ها هر ۵ دقیقه در صفحه قابل‌مشاهده تازه می‌شوند. محدودیت API، خطای شبکه و داده قبلی پنهان نمی‌شوند. توکن یا credential درخواست/ذخیره نمی‌شود.

بلاگفا بازنشسته است و درخواست پایش برای آن ارسال نمی‌شود. این پنل فقط خواندنی است؛ مدل‌ها، زمان‌بندی و کنترل کیفیت تولید را تغییر نمی‌دهد.

## آزمون و استقرار
```sh
node --test tests/status_data.test.cjs tests/status_repair.test.cjs tests/status_priorities.test.cjs
```
۶۳ آزمون قرارداد داده و استقرار، شامل آزمون‌های مستقل تازگی انتشار/وضعیت اجرا، جمع داده قدیمی و ناموجود، پوشش زمانی و یکسانی فیلتر جست‌وجو/CSV.

آزمون اختیاری مرورگر با Playwright و Chromium:
```sh
# به Playwright و مرورگر نصب‌شده نیاز دارد؛ مسیر مرورگر قابل تنظیم است.
CHROMIUM_PATH=/path/to/chromium node tests/status_priorities.browser.cjs
```
تمام پاسخ‌های API و فایل‌های عمومی در این آزمون کنترل‌شده‌اند؛ هیچ انتشار یا تغییر مخزن انجام نمی‌شود. آزمون عنوان همه هفت وبلاگ را بدون بازکردن برگه‌ها، جست‌وجو/CSV، تازه‌سازی ناموفق رسیدها، هشدار عنوان ناقص و نمایش موبایل ۳۹۰ پیکسل بررسی می‌کند. این آزمون جایگزین تأیید استقرار زنده نیست.

## سه وضعیت مستقل و پوشش آمار
- نتیجه workflow، تازگی آخرین انتشار ثبت‌شده و کیفیت داده جدا نمایش داده می‌شوند؛ اجرای جاری یا توقف عمدی هشدار انتشار قدیمی را نمی‌پوشاند.
- دریافت موفق فایل، اثبات انتشار تازه یا سلامت زنده وبلاگ نیست. زمان آخرین دریافت موفق رسید هر وبلاگ نمایش داده می‌شود.
- اگر مجموع از داده قبلی استفاده کند، تعداد وبلاگ‌های با داده قدیمی کنار همان کارت ذکر می‌شود. منبع ناموجود همچنان نامشخص است؛ مجموع ناقص با ≥ مشخص می‌شود.
- تعداد رسید دارای زمان معتبر و بدون زمان معتبر در نمای کلی و جزئیات وبلاگ نمایش داده می‌شود. رسیدهای بدون زمان معتبر در بازه ۲۴ ساعت/۷ روز شمرده نمی‌شوند.

گردش‌کار `afp-agri-v2-dashboard.yml` ابتدا آزمون‌ها را اجرا و سپس تمام فایل‌های این پوشه را کنار داشبورد کشاورزی موجود منتشر می‌کند.
