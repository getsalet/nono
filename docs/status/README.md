# پنل وضعیت وبلاگ‌ها

نشانی: https://getsalet.github.io/nono/status/

## برگه‌ها
- نمای کلی هفت وبلاگ، زمان آخرین انتشار و آمار ثبت‌شده.
- صفحه مستقل هر وبلاگ: رسیدها، صف، موانع کیفی، اجراها، زمان‌بندی و منابع.
- آرشیو انتشارها با جست‌وجو، فیلتر، صفحه‌بندی و خروجی CSV.
- وضعیت مخزن: آخرین commitها، نمونه ۱۰۰ اجرای اخیر، خطاهای دسترسی به منابع.
- راهنما و توضیح محدودیت شمارش.

## تعریف و تازگی داده
آمار تعداد پست‌ها از رسیدهای یکتای مخزن است، نه شمارنده تمام مطالب عمومی یا آمار بازدید. زمان انتشار از رسید می‌آید؛ وبلاگ‌ها هنگام نمایش پنل مستقیماً وارسی نمی‌شوند. شماره آخرین پست تعداد کل فرض نمی‌شود. بازیابی با زمان اولیه نامشخص در آمار ۲۴ ساعت/۷ روز وارد نمی‌شود. داده ناموجود، نامشخص است نه صفر.

دو درخواست API عمومی، commit و نمونه اجراها را دریافت می‌کنند. فایل‌ها در صورت دریافت SHA از همان نسخه ثابت خوانده می‌شوند؛ fallback به main صریح گزارش می‌شود. فایل‌های بزرگ صف فقط با باز کردن برگه یا انتخاب وبلاگ بارگیری می‌شوند. ساعت نسبی هر ۳۰ ثانیه و داده‌ها هر ۵ دقیقه در صفحه قابل‌مشاهده تازه می‌شوند. محدودیت API، خطای شبکه و داده قبلی پنهان نمی‌شوند. توکن یا credential درخواست/ذخیره نمی‌شود.

بلاگفا بازنشسته است و درخواست پایش برای آن ارسال نمی‌شود. این پنل فقط خواندنی است؛ مدل‌ها، زمان‌بندی و کنترل کیفیت تولید را تغییر نمی‌دهد.

## آزمون و استقرار
```sh
node --test tests/status_data.test.cjs
```
۲۴ آزمون قرارداد داده و استقرار؛ همچنین ۲۲ بررسی مسیر در دو اندازه ۱۴۴۰ و ۳۹۰ پیکسل و تست جست‌وجو/فیلتر، منوی موبایل، حالت تاریک و قطع منابع اجرا شدند. تست‌های رابط با پاسخ‌های کنترل‌شده و داده‌های موجود مخزن انجام شده‌اند؛ جایگزین تأیید استقرار زنده نیستند.

گردش‌کار `afp-agri-v2-dashboard.yml` ابتدا آزمون‌ها را اجرا و سپس تمام فایل‌های این پوشه را کنار داشبورد کشاورزی موجود منتشر می‌کند.
