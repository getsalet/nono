# Vazir web font

- Family: **Vazir** (وزیر), original v30.1.0, not a replacement family.
- Upstream: https://github.com/rastikerdar/vazirmatn/tree/v30.1.0
- Font source: https://raw.githubusercontent.com/rastikerdar/vazirmatn/v30.1.0/dist/Vazir-Variable.woff2
- License: SIL Open Font License 1.1; the full original notice is in `OFL.txt`.
- SHA-256 of the unmodified WOFF2: `3d7c6820aa45e4f1c569561a7dabc6472153e14ea883b5b6ef41aa764c66def0`.

`vazir.css` embeds that original WOFF2 as a data URL. The CSS and font are
served from this Pages site, without depending on a remote font CDN or a
locally installed font. `font-display: swap` keeps content readable while loading.
The variable face supplies the UI weights; technical IDs remain monospace.
