قرائت درست وضعیت

قواعدی که از تفسیر بیش‌ازحد جلوگیری می‌کنند.

  • موفقیت workflow با انتشار عمومی و تأیید عنوان، بدنه، لینک‌ها و تصویر یکی نیست.
  • رسید native مبهم یا draft تغییرکرده هرگز با ارسال مجدد کورکورانه حل نمی‌شود.
  • مدل تنظیم‌شده از مدل اثبات‌شده در هر درخواست واقعی جدا گزارش می‌شود.
  • داده‌های این صفحه فقط از فایل‌های عمومی مخزن و API عمومی GitHub خوانده می‌شوند.
