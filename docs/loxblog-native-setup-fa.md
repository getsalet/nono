# آماده‌سازی بومی لوکس‌بلاگ AFP

وبلاگ: https://afp.lxb.ir/

## قالب نصب‌شده

فایل‌های `templates/loxblog/` برای فیلدهای جداگانهٔ پنل `adminnew.php?page=themeedit` هستند:

| فایل | فیلد بومی |
|---|---|
| header.html | themeheader |
| footer.html | themefooter |
| index.html | theme |
| article.html | themee |
| category.html | themecat |
| page.html | themepage |
| 404.html | theme404 |
| offline.html | themeoffline |

قالب از `[LX:Head]` برای متاهای بومی، canonical، RSS و عنوان استفاده می‌کند. تگ Google Search Console و لوگوی واقعی AFP اضافه شده‌اند. نظرات و فرم نظر عمداً در قالب درج نشده‌اند؛ ناشر نیز باید `comment_status=0` بفرستد.

نمایش صفحهٔ نخست و صفحات داخلی روی شش نوشته تنظیم شده است. مرتب‌سازی بومی `indexpostsorder=publish_at` است. صفحه‌بندی از `<LX:Blog_Page_Block>` و `[Blog_Page]` استفاده می‌کند؛ نه لیست دستی آخرین مطالب. تعداد شش کارت و عدم هم‌پوشانی صفحات پس از وجود حداقل هفت مطلب واقعی باید آزموده شود؛ در زمان نصب وبلاگ خالی بود.

## انتشار بومی؛ موارد شناسایی‌شده، نه ادعای اجرای جنراتور

صفحهٔ ورود: https://loxblog.com/login.php
صفحهٔ ارسال: `adminnew.php?page=sendpost`

فیلدهای مشاهده‌شده: `ptitle`, `pslug`, `pimage`, `ptext` (TinyMCE editor1), `pextext` (editor2), `cats[]`, `keywords`, `status`, `is_pinned`, `show_to`, `comment_status`, `publish_at`, `meta_description`.

- `status=1`: انتشار عادی؛ `status=0`: پیش‌نویس.
- `show_to=1`: نمایش عمومی.
- `comment_status=0`: هیچ نظری برای این نوشته پذیرفته نشود.
- خلاصه باید واقعاً در `ptext` و ادامه در `pextext` ذخیره شود. `expostmode=2` برای نمایش خلاصه و ادامه در صفحهٔ تکی حفظ شده است. قالب هیچ CSS برش/مخفی‌سازی متن کامل ندارد.
- ورود کد تصویری دارد. اجرای بدون‌نظارت و تمدید نشست باید جداگانه و واقعی آزموده شوند؛ ورود تعاملی موفق، مدرک موفقیت ورود از GitHub Actions نیست.

## ایراد فرم تنظیمات پنل

کد رابط میزبان selectهای تنظیمات را از فرم بیرون منتقل می‌کند. در بررسی DOM، `select.form` تهی بود و FormData فرم آن‌ها را شامل نمی‌شد؛ ارسال عادی باعث برگشت مقادیر کشویی به پیش‌فرض شد. برای ذخیرهٔ درست، selectهای موجود به همان فرم از طریق ویژگی استاندارد `form` متصل شدند، مقادیر صحیح انتخاب و دکمهٔ بومی ذخیره کلیک شد. بازخوانی مستقل مقادیر پایدار را تأیید کرد. این صرفاً رفع ارتباط DOM فرم است، نه تغییر سرور یا دورزدن اعتبارسنجی.

## معیار پذیرش جنراتور مستقل

تا پیش از تکمیل و آزمون واقعی زیر، زمان‌بندی خودکار نباید فعال یا سالم اعلام شود:

1. اسرار اختصاصی لوکس‌بلاگ فقط در GitHub Secrets، خارج از فایل و لاگ.
2. صف و state مستقل؛ تنها جغرافیا/لینک‌های مرجع مشترک، نه متن و عنوان تکراری.
3. کنترل اصالت بین همه وبلاگ‌ها، تصویر با خانوادهٔ درست و ارزیابی اجباری تصویر، مقالهٔ فارسی ۵۰۰–۱۰۰۰ کلمه با سه FAQ واقعی.
4. سقف سه انتشار تأییدشده در هر ۶۰ دقیقه، بررسی کم‌هزینهٔ ظرفیت قبل از فراخوانی تولید.
5. بررسی آرشیو عمومی و بومی قبل از ارسال، یک ارسال بومی، ژورنال پیش از ارسال و توقف هنگام نتیجهٔ نامطمئن؛ عدم ارسال مجدد کور.
6. آزمایش یک انتشار واقعی از runner میزبانی‌شده، بررسی URL و متن کامل/خلاصه/تصویر/لینک/FAQ/نبود نظرات در سایت عمومی، ثبت checkpoint ماندگار و سپس تأیید اجرای زمان‌بندی‌شده.

این تغییر فقط قالب و مستندات شناسایی را اضافه می‌کند؛ جنراتور لوکس‌بلاگ هنوز مستقر یا فعال نشده است.
