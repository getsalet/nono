# استفاده از تصویر همان مقالهٔ مرجع

درخواست کاربر: به‌جای ساخت تصویر تازه برای مقاله‌های وبلاگی، از تصویر مرتبطِ همان پست در سایت استفاده شود.

- اولویت تصویر مرتبطِ متعلق به صفحهٔ مقصد همان بک‌لینک در navar-abyari.ir است؛ لوگو، منو، تبلیغات، کارت مطالب مرتبط یا تصویر محصول دیگر جایگزین نمی‌شوند.
- نشانی اصلی تصویر در src می‌ماند؛ دانلود و بارگذاری مجدد، ساخت واترمارک تازه یا افزودن لینک سوم انجام نمی‌شود. متن جایگزین کوتاه و مرتبط است، نه تکرار کلیدواژه.
- عضویت تصویر در همان صفحه، اندازه و دسترسی فایل، هویت محصول و ارتباط تصویری با مقاله بررسی و SHA-256 ثبت می‌شود. امتیاز واقعی بازبین حداقل ۹۰ لازم است؛ امتیاز تغییر داده نمی‌شود.
- پیش از انتشار، تعلق تصویر به صفحهٔ مرجع و ثابت‌بودن بایت‌ها دوباره بررسی می‌شود. تصویر عوض‌شده یا حذف‌شده اجازهٔ انتشار با تأیید قدیمی ندارد.
- نبود تصویر مناسب یا قطع بازبین برای مقالهٔ کاملاً متنی: انتشار بدون تصویر؛ نه عکس جعلی یا عمومی. مقاله‌ای که به عکس یا نمودار وابسته است: توقف و بازبینی، بدون ساخت خودکار تصویر جدید.
- کارگر و هماهنگ‌کننده برای این مقاله‌ها تصویر جدید سفارش نمی‌دهند. تغییر فقط کار آینده و پیش‌نویس‌های منتشرنشده است؛ پست‌های منتشرشده خودکار بازنویسی نمی‌شوند.
- اصالت و کیفیت متن، دو مقصد مرتبط، بودجه، توقف اضطراری و جلوگیری از تکرار حفظ می‌شوند؛ بلوگفا بازنشسته و تولید لوله نخی متوقف است.
- استفاده از یک URL اصلی به کش و جلوگیری از نسخه‌های اضافی کمک می‌کند؛ تضمین افزایش اعتبار تصویر یا رتبه نیست. مطالب باید مستقل و مفید باشند، نه صرفاً صفحات ساخته‌شده برای دستکاری رتبه.
