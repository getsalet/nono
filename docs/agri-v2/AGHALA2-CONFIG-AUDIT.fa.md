## مسیر واقعی قدیمی

گردش‌کار city-content-queue.yml، run_agnes_city_queue_fast.py را اجرا می‌کند؛ سپس resilient → seo → run_agnes_city_queue.py. تنظیمات گردش‌کار: متن agnes-3.0-flash و تصویر agnes-image-2.0-flash. ماژول image_quality_gate.py در این زنجیره نصب نشده است؛ وجود فایل به معنی اجرای آن نیست. همچنین خود آن ماژول در خطای بازبین مسیر پذیرش خودکار دارد؛ آن رفتار نباید منتقل شود.

درخواست تصویر قدیمی: همان API /v1/images/generations، return_base64، extra_body.response_format و مرجع تصویر؛ timeout=600 و size=1024x768. خروجی با برش مرکزی به 16:9 تبدیل می‌شد. پرامپت اصلی برای همه نقش‌ها یک بسته سالم AFP روی خاک است و لوله، فیلتر و اتصال را منع می‌کند. مرجع خانواده محصول ارسال می‌شود.

## تفاوت فعلی

مدل تصویر 2.1، مدل متن 2.5، timeout تصویر 180، اندازه بومی 1K و ratio=16:9. حذف برش مرکزی برای حفظ محصول عمدی است و ناسازگاری API ثابت نشده است. نقش سوم فعلی فیلتر واقعی متصل با بسته جداگانه می‌خواهد؛ نقش دوم هویت گیاه و مرحله رسیدگی را بررسی می‌کند. ورودی‌های نقش‌دار به‌جای تنها مرجع بسته استفاده می‌شوند. این‌ها مسئله تصویری پیچیده‌تری از نسخه قدیمی می‌سازند؛ نه یک انتقال همسان.

بازبین فعلی هر سه تصویر را با ۱۵ فیلد بررسی می‌کند؛ حد امتیاز طبق دستور مالک >90 است و فقط مقیاس بسته غیرحیاتی است. ماژول QA قدیمی اگر اجرا می‌شد حد پیش‌فرض 70 داشت، ولی نباید این مقدار را حد واقعی گردش‌کار فعال قدیمی قلمداد کرد.

## اشکال‌های قطعی و اصلاح

1. خطای محلی JSON/پروتکل از CapabilityError ارث می‌برد و چرخه هر CapabilityError را یک قطعی عمومی سرویس تلقی می‌کرد. این استنتاج نادرست بود. اکنون تنها خطای انتقال/HTTP واقعی موجب مدار انتظار می‌شود؛ خطای متن، اعتبارسنجی و کیفیت مستقل گزارش می‌شوند.
2. علت خطا بیش از حد حذف می‌شد؛ رسید نخستین چرخه فقط پیام عمومی داشت. اکنون نوع، دسته مجاز و وضعیت HTTP ثبت می‌شود؛ هیچ پاسخ خام، متن استثنا یا کلیدی ذخیره نمی‌شود. خطای قدیمی به‌طور پسینی قابل تعیین نیست.
3. تجزیه متن نسبت به قدیم شکننده بود؛ استخراج JSON از قاب Markdown/توضیح اضافی و JSON رشته‌شده بازگردانده شد. پاسخ بریده، نامعتبر یا غیرشیء همچنان رد می‌شود. این اصلاح ادعای رفع قطعی خطای اجرای پیشین نیست.
4. فرصت تصویر از 600 به 180 ثانیه کاهش یافته بود. به 600 بازگردانده شد؛ افزایش فرصت به معنی اثبات وقوع timeout در اجرای قبلی نیست.

## شواهد توقف اخیر

رسید نقش لوبیا چیتی: images_done=0، status=incomplete؛ هیچ model-candidate.json یا article.json جدیدی در تغییرات آن اجرا ذخیره نشد و مسیریابی تصویر تغییر نکرد. خطا پیش از نخستین تصویر رخ داد. دریافت لاگ خام Actions از مسیر خواندنی عمومی با 403 مواجه شد؛ ازاین‌رو تعیین HTTP، JSON، مدل یا شبکه برای این خطای تاریخی ممکن نیست. این توقف شاهد خرابی سرویس تصویر نیست.
