# انتخاب کلید آزاد برای تولید تصویر

انتخاب پیش از درخواست، از استخر `eligible_image_slots` انجام می‌شود؛ تأیید متنی به‌تنهایی کلید را وارد این استخر نمی‌کند. از ۱۵ جایگاه پیکربندی‌شده، جایگاه ۸ تکرار جایگاه اول است؛ فعلاً فقط جایگاه اول شاهد موفق برای مدل `agnes-image-2.1-flash` دارد. بنابراین این تغییر به‌معنای آماده‌بودن ۱۴ مسیر تصویر نیست و هیچ شاهد سلامت تازه‌ای جعل یا تاریخ قبلی نوسازی نشده است.

## رفتار پیاده‌شده

- کلیدهای هم‌مقدار فقط یک مسیرند؛ نام کلیدهای خارج از ۱۵ جایگاه رد می‌شود.
- میان کلیدهای تأییدشده، توزیع گردشی با cursor پایدار انجام می‌شود؛ کلید دارای توقف اختصاصی فعال، خطای احراز هویت، منع دسترسی تصویر، محدودیت سهمیه یا نرخ کنار گذاشته می‌شود.
- وضعیت مشترک سرویس از main و توقف محلی از circuit خوانده می‌شود. توقف مشترک، صف پر و منع پرداخت با انتخاب کلید دیگر دور زده نمی‌شوند.
- پس از گرفتن نوبت صف اشتراکی، مجوز دوباره کنترل می‌شود تا تغییر وضعیت بین انتخاب و ارسال نادیده نماند.
- هر درخواست تصویر همچنان حداکثر یک ارسال دارد. خطای 429/503، timeout یا سهمیه باعث زنجیرهٔ درخواست روی کلیدهای دیگر نمی‌شود. بودجهٔ backtest و بازیابی قدیمی افزایش یا بازنشانی نشده است.
- وضعیت مسیریابی فقط نام جایگاه و cursor را ذخیره می‌کند؛ نه مقدار کلید، نه اثرانگشت آن.

## حدود این تغییر

برای واردکردن کلیدهای باقی‌مانده، شواهد جدید و مدل‌اختصاصی تصویر لازم است. استخر کلید، ظرفیت آزادِ سرویس را به‌صورت لحظه‌ای اندازه‌گیری نمی‌کند؛ فقط مسیرهای واجد شرایط را با استفاده از شواهد سلامت و توقف‌ها انتخاب می‌کند. تفکیک سهمیهٔ حساب‌ها باید بر پایهٔ امکانات/قرارداد ارائه‌دهنده باشد، نه حدس از متفاوت‌بودن رشتهٔ کلیدها. آزمون انبوه پرداختی یا تعویض کلید پس از صف پر، جزو این تغییر نیست.

آخرین backtest در اجرای `40153153132` دوباره با `503 image_queue_full` متوقف شد: دو کنترل منفی رد و کنترل مثبت مستقل پذیرفته شدند، اما تصویر تازهٔ Agnes ساخته نشد. این تغییر کد نیز هیچ تولید یا انتشار تازه‌ای را اثبات نمی‌کند.

۱۴۰ تست آفلاین پاس شدند، شامل ۹ تست جدید برای گردش یکتا، پرش از توقف اختصاصی، حفظ توقف مشترک و عدم ذخیرهٔ رازها.
