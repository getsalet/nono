# تغییر مدل تصویر به 2.1

- مدل فعال تولید تصویر: `agnes-image-2.1-flash`، خوانده‌شده از config؛ مدل متن بدون تغییر `agnes-2.5-flash` است.
- آزمون واقعی GitHub Actions: `40139544578`. یک درخواست با تصویر مرجع AFP، همان دستور تصویر دوم مقالهٔ آزمایشی و همان کلید اول؛ HTTP 200 و فایل WebP معتبر در ۱۸٫۸۷ ثانیه. ارائه‌دهنده نام مدل اجراشده را در پاسخ اعلام نکرد؛ نام مدل درخواست‌شده 2.1 است.
- شواهد مدل جدید فقط برای کلید اول ثبت شده‌اند؛ کلیدهای دیگر برای این مدل آزمایش نشده‌اند. اعتبار شواهد متن قدیمی تمدید نشده است.
- بازبینی تصویری توسط Notion AI: تصویر برای انتشار رد شد؛ نمای نزدیکِ رو به پایین و غلاف خشک رعایت نشده، غلاف‌های قرمز تازه‌نما و بسته‌بندی بیش از اندازهٔ درخواستی دیده می‌شود. برچسب تلفن خوانا و صحیح است. این بازبینی، تأیید انسانی یا کشاورزی تخصصی نیست.
- تصویر آزمایشی به وردپرس ارسال نشده است. تصویر اول قبلی و توقف انتشار همان مقاله حفظ شده‌اند؛ مقالهٔ جدیدی با این تغییر منتشر نشده است.
- کد درخواست تولید با قالب آزمون موفق یکسان شده، پارامتر غیرضروری `n` حذف و کنترل ناسازگاری مدل پاسخ افزوده شده است. ثبت منشأ تصویر از مدل فعال استفاده می‌کند. آزمون تفاضلی تاریخی همچنان به مدل قدیمی 2.5 مقید است تا سابقه عوض نشود.
- نتیجهٔ آزمون محلی پس از تغییر: ۹۴ آزمون موفق.
- مرحلهٔ بعدیِ مقالهٔ آزمایشی: اصلاح دستور دقیق ریخت‌شناسی لوبیای خشک، تولید و تأیید بصری تصویرهای باقی‌مانده با بودجهٔ محدود؛ این تغییر بودجه‌های تمام‌شدهٔ قبلی را بازنشانی نمی‌کند و مجوز انتشار تصویر مردود نیست.
