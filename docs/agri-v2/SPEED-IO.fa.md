# بهینه‌سازی دریافت منابع

- دریافت حداکثر شش منبع مستقل با سه worker، با حفظ ترتیب ورودی و شناسه‌های شواهد.
- کش متنی منابع برای حداکثر شش ساعت؛ URL، زمان دریافت، طول متن و SHA256 قبل از استفاده بررسی می‌شود. زمان دریافت اصلی حفظ می‌شود؛ پاسخ مدل منبع محسوب نمی‌شود.
- خطاها کش نمی‌شوند و retry اضافی ندارند. بررسی نشانی عمومی، دامنه دانشگاهی/دولتی، منع redirect و سقف اندازه در fetcher اصلی باقی است.
- موجودی کامل وردپرس فقط در گذار مستقیم پژوهش به تولید، اگر کمتر از پنج دقیقه عمر داشته باشد، بازاستفاده می‌شود. کش موجودی بین اجراها وجود ندارد؛ بررسی مجوز انتشار و تعارض slug هنگام انتشار همچنان اجرا می‌شود.
- درخواست مدل یا تولید تصویر موازی نشده است؛ cooldown و گردش کلید، سقف تلاش و دو تصویر تغییر نکرده‌اند.
- ۲۶۹ آزمون آفلاین پاس شده است. بهبود زمان انتها‌به‌انتها در محیط زنده هنوز اندازه‌گیری نشده؛ تأخیر GitHub Actions و رد محتوایی با این تغییر حذف نمی‌شود.
